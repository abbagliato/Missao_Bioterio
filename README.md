# Missão Biotério

Jogo de labirinto em HTML/CSS/JavaScript (arquivo único): você é o(a) técnico(a) de biotério levando o lote por 6 setores (cuidado com o analista da qualidade, que registra não conformidades) (Quarentena, Fundação, Produção, Reservado, Higienização e Expedição), 60 segundos por setor, com ranking Top 10 salvo no navegador.

Abra `index.html` no navegador ou use o GitHub Pages.
