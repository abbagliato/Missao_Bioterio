# Missão Biotério

Jogo de labirinto em HTML/CSS/JavaScript (arquivo único): você é o(a) analista da qualidade e audita 6 setores do biotério (Quarentena, Fundação, Produção, Reservado, Higienização e Expedição), 60 segundos por setor, com ranking Top 10 salvo no navegador.

Abra `index.html` no navegador ou use o GitHub Pages.
